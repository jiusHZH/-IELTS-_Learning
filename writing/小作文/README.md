# IELTS 小作文（Writing Task 1）

本目录整理 IELTS Academic Writing Task 1 的课堂笔记，重点保留能在考场中反复使用的审题、分组、概述和数据描述方法。

## 笔记目录

- [数据图表](./数据图表.md)：线图、饼图、柱状图；趋势、分组、数据比较和常用表达。
- [地图题](./地图题.md)：时态、空间位置、设施变化和整体概述。
- [流程图](./流程图.md)：步骤顺序、被动语态、过程描述和概述。

## 通用写作流程

1. **审题**：确认图表类型、描述对象、时间范围、单位和时态。
2. **Introduction**：用一句话改写题干，说明图表展示什么。
3. **Overview**：概括最明显的趋势、差异、极值或整体变化。
4. **Details**：先分组，再选择关键数据或变化进行比较。
5. **检查**：核对数据、时态、主谓一致、单复数和比较结构。

## 推荐结构

通常可以采用四段式：

1. Introduction
2. Overview
3. Details 1
4. Details 2

这是便于执行的常用结构，不是僵硬模板。应根据图表信息调整主体段的分组方式。

## 核心原则

- **先看整体，再写细节**：不要看到一个数字就写一个数字。
- **先分组，再落笔**：优先根据趋势、大小、类别或空间关系组织信息。
- **突出关键特征**：关注总体趋势、最大值和最小值、起止数据、峰值、交叉点及明显差异。
- **准确胜过复杂**：使用自己能掌握的清晰句型，不为了显得高级而堆叠表达。
- **Overview 不等于 Conclusion**：小作文通常写概述段，不需要像大作文一样总结立场或提出观点。
