# 地图题

地图题主要考查对空间位置和地点变化的准确描述。写作时先判断时间关系，再选择空间顺序和变化类型来组织段落。

## 1. 审题与时态

先确认地图展示的是：

- 过去与现在的对比；
- 两个过去时间点的对比；
- 现状与未来规划的对比。

常用时态：

- 描述过去的布局：一般过去时，如 *There was a fountain in the centre.*
- 描述现在的布局：一般现在时，如 *A café stands near the entrance.*
- 描述从过去到现在已经发生的变化：现在完成时或现在完成时被动语态，如 *The fountain has been replaced by a garden.*
- 描述未来规划：根据题目语境使用 *will*、*is planned to* 或 *is expected to* 等表达。

不要仅凭“地图题”这个题型统一使用某一种时态，必须以地图标注的时间为准。

## 2. Introduction：简洁改写题干

常用结构：

- *The maps compare the layout of ... in YEAR and today.*
- *The plans show how ... changed between YEAR and YEAR.*
- *The maps illustrate the proposed changes to ...*

例如：

> The maps compare the original layout of Grange Park with its current design.

首段说明地点和比较范围即可，不要在这里提前描述所有变化。

## 3. 主体段：如何组织空间信息

一种实用方法是按地图划分段落：第一段描述早期布局，第二段按相同的空间顺序描述后来的变化。若地图内容特别复杂，也可以根据清晰的区域或功能分组。

描述单张地图时，可以按照以下顺序：

- 从入口或最显眼的设施开始；
- 描述中心区域；
- 按顺时针、逆时针或从一侧到另一侧介绍其余设施；
- 使用位置关系把句子连接起来，避免像清单一样逐项罗列。

## 4. 常用空间表达

| 表达 | 含义 |
|---|---|
| in the centre of | 在……中心 |
| in the northern part of | 在……北部 |
| in the northeast corner | 在东北角 |
| on the left/right side of | 在……左侧/右侧 |
| next to / adjacent to | 紧邻 |
| opposite | 在……对面 |
| between A and B | 在 A 和 B 之间 |
| along the northern edge | 沿着北侧边缘 |
| near the entrance | 在入口附近 |
| surrounded by | 被……环绕 |

方向词要以地图为准。地图没有提供明确方向时，不要自行猜测方位。

## 5. 描述变化的常用句型

### 新增

- *A new café has been added near the entrance.*
- *A children's play area has been built in the northeast corner.*

### 替换或改造

- *The circular fountain has been replaced by a rose garden.*
- *The stage has been transformed into an amphitheatre.*

### 拆除或消失

- *The glasshouse has been removed.*
- *The original building no longer exists.*

### 位置迁移

- *The seating area has been relocated to the western side.*

### 保持不变

- *The rose garden has remained in the same location.*
- *The entrance has remained unchanged.*

使用被动语态时要注意动词形式：*has been replaced*、*has been removed*、*has been relocated*。

## 6. Overview：概括整体变化

概述段优先说明：

- 地点整体上是变得更现代、开发程度更高，还是基本保持原貌；
- 哪些主要设施被新增、替换或移除；
- 是否有重要设施保留了下来。

例如：

> Overall, the park has been modernised considerably, with several new recreational facilities added while some original features have been retained.

这只是句型示例。只有在地图确实支持这些判断时，才能使用相应描述。

## 7. 常见问题自检

- 是否根据地图时间选择了时态？
- 是否先概括整体变化，再写具体位置？
- 是否有清晰的空间描述顺序？
- 是否使用了准确的位置关系，而不是重复 *there is*？
- 是否区分了新增、替换、拆除、迁移和保留？
- 是否避免把地图中没有的信息写进去？
