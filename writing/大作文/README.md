# IELTS 大作文（Writing Task 2）

本目录按照**通用写作方法和题型**组织笔记，不再按照 Lesson 编号堆叠课堂内容。

## 笔记目录

- [General.md](./General.md)：适用于多种题型的基础结构、主体段展开和审题原则。
- [Discussion.md](./Discussion.md)：Discuss both views and give your own opinion 等双方观点讨论题。
- [Opinion.md](./Opinion.md)：Agree / Disagree、To what extent 等观点表达题。目前尚待课堂内容补充。
- [Positive_or_Negative.md](./Positive_or_Negative.md)：Positive or Negative Development 题。目前记录 Lesson 3 作业，专项方法尚待补充。

## 维护原则

1. **通用方法放在 General**：适用于多种题型的结构、论证和审题方法集中维护在这里。
2. **题型方法单独归档**：只把具有题型针对性的写作安排放进对应文件。
3. **避免重复**：其他文件需要引用通用方法时，链接到 General，不复制整段内容。
4. **区分已学与待补充**：课堂尚未讲解或笔记尚无依据的方法，明确标记为待补充，不提前写成既定规则。
5. **保留适用边界**：推荐方法不等于固定模板；如果某种安排并非所有题目都适用，需要明确说明。
