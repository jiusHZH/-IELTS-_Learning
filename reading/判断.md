# IELTS Reading｜判断题（True / False / Not Given）

> 本文件用于持续维护 IELTS Reading 判断题的核心逻辑、考点规律与做题方法。

## 1. 题型特征

- 判断题**通常按原文顺序出现**。
- 可以利用题目顺序缩小定位范围。
- 建议一次预读相邻 **2 道左右** 的题目，配合平行阅读，而不是每做一道题就重新扫描全文。

---

## 2. True / False / Not Given 的本质

### TRUE

> 原文支持题干的核心事实。

表现形式可以是：

- 同义替换
- 改写
- 原文信息的合理归纳与概括

### FALSE

> 原文明确信息与题干矛盾，两者不能同时成立。

核心判断：

> **不可共存。**

### NOT GIVEN

> 原文没有提供足够信息判断题干是否成立。

常见情况：

1. 原文完全没有对应信息。
2. 找到了相关人物 / 事件 / 主题，但题干新增的关键信息原文没有说明。
3. 题干与原文可以同时成立，但原文没有证明题干。

最稳定的判断框架：

> **TRUE：原文支持。**  
> **FALSE：原文反驳。**  
> **NG：原文既不支持，也不反驳。**

> 注意：“我没找到”不等于 NG。NG 的依据是原文没有给出足够信息，而不是个人定位失败。

---

## 3. 考点唯一性

### 核心规律

> **一道判断题通常围绕一个决定 T / F / NG 的核心信息差设置考点。**

因此做题时不需要对题干每一个词投入同等注意力。

可以优先：

1. 抓句子主干
2. 找核心判断关系
3. 判断哪个信息最可能决定 T / F / NG
4. 其他修饰信息先降权处理

课堂提速思路：

> **主干优先，考点唯一；修饰语默认降权，敏感信息除外。**

### 从句处理原则：主句优先，从句降权

**从句通常用于补充背景、描述对象和提供定位信息，一般不是主要挖坑的位置。**

- **主句优先**：优先阅读主句，寻找核心考点。
- **从句降权**：如果主句已经找到明确考点，从句通常可以快速略读，不必逐词分析。
- **例外情况**：如果从句中出现明显的绝对化、排他性表达，需要提高警惕。

尤其注意：

- **范围**：all / only / none
- **程度**：completely / entirely
- **绝对判断**：always / never

这些表达可能改变句子的范围、程度或判断结果，不能因为它们出现在从句中就直接忽略。

> **记忆原则：主句优先，从句定位；绝对表达重点检查，不要机械删除从句。**

### 判断题敏感信息检查清单

以下信息在对照整道题与原文时都值得留意：

- **范围**：all / some / most / only
- **程度**：completely / significantly / slightly
- **时间**：before / after / currently / eventually / first
- **比较**：more / less / the most
- **否定**：not / never / rarely
- **情态**：may / can / must / will
- **因果**：because / lead to / result in / result from
- **条件**：if / when / among / in certain groups
- **数字 / 年份 / 比例**

注意：这是一份整体判断时的检查清单，并不意味着这些词只要出现在从句中，就一定是考点。从句仍然按照“主句优先、从句降权”的原则处理，尤其留意上面列出的绝对化、排他性表达。

## 4. 拆句方法

判断题可以拆成：

> **谁 + 做什么 + 范围 / 程度 + 时间 / 条件 / 原因**

例如：

> Most young people prefer online shopping because it is cheaper.

可以拆为：

- 主体：young people
- 范围：most
- 行为：prefer online shopping
- 原因：cheaper

其中任何一个关键信息发生变化，都可能影响答案。

---

## 5. 平行阅读法

不要：

> Q1 → 搜全文 → Q2 → 再搜全文 → Q3 → 再搜全文

建议：

> 一次看 2 道左右题目  
> → 记住定位词与核心考点  
> → 按原文顺序阅读  
> → 一次阅读解决多题

利用顺序性：

> 上一道题答案位置  
> → 当前题答案区域  
> → 下一道题答案位置

这样可以不断压缩搜索区间。

---

## 6. 判断题核心流程

1. 读题干，抓主体和核心关系。
2. 划定位词。
3. 找可能的唯一核心考点。
4. 定位原文。
5. 对比题干与原文：
   - 支持 → TRUE
   - 明确矛盾 → FALSE
   - 信息不足 → NOT GIVEN
6. 若题干含敏感限定词，再重点复核范围、时间、程度、因果等信息。

---

## 7. 一句话总结

> **定位词负责“去哪里找”，考点负责“判断什么”，同义替换负责“建立对应”，原文证据负责“决定 T / F / NG”。**
